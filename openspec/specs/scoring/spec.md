# scoring Specification

## Purpose
Результат партии: счётчики очков, очищенных линий и уровня, классическая таблица очков за удаление 1–4 линий с множителем уровня и правило повышения уровня.

## Requirements

### Requirement: Счётчики партии
Игра SHALL хранить три целочисленных счётчика: очки, общее число удалённых линий и уровень. В начале каждой новой партии все три счётчика SHALL быть равны 0. После окончания партии счётчики SHALL сохранять свои последние значения, пока не начнётся новая партия.

#### Scenario: Счётчики новой партии
- **WHEN** начинается новая партия
- **THEN** очки равны 0, линии равны 0, уровень равен 0

#### Scenario: Сброс после предыдущей партии
- **WHEN** в предыдущей партии было 1500 очков, 12 линий и уровень 1, и начинается новая партия
- **THEN** очки, линии и уровень равны 0

#### Scenario: Счётчики после конца игры
- **WHEN** партия оканчивается при 340 очках, 5 линиях и уровне 0
- **THEN** игра по-прежнему сообщает 340 очков, 5 линий и уровень 0

### Requirement: Начисление очков за линии
За фиксацию, удалившую N строк, игра SHALL прибавлять к очкам значение `B × (L + 1)`, где L — уровень до этой фиксации, а B — базовое значение: 40 при N = 1, 100 при N = 2, 300 при N = 3, 1200 при N = 4. Фиксация без удалённых строк SHALL NOT изменять очки.

#### Scenario: Одна линия на уровне 0
- **WHEN** на уровне 0 при 0 очках фиксация удаляет 1 строку
- **THEN** очки равны 40

#### Scenario: Четыре линии на уровне 0
- **WHEN** на уровне 0 при 0 очках фиксация удаляет 4 строки
- **THEN** очки равны 1200

#### Scenario: Две линии на уровне 2
- **WHEN** на уровне 2 при 500 очках фиксация удаляет 2 строки
- **THEN** очки равны 800 (500 + 100 × 3)

#### Scenario: Три линии на уровне 9
- **WHEN** на уровне 9 при 0 очках фиксация удаляет 3 строки
- **THEN** очки равны 3000

#### Scenario: Фиксация без линий
- **WHEN** фиксация не удаляет ни одной строки
- **THEN** очки не меняются

### Requirement: Подсчёт линий
После каждой фиксации игра SHALL увеличивать общее число линий на число строк, удалённых этой фиксацией.

#### Scenario: Накопление линий
- **WHEN** при 7 линиях фиксация удаляет 3 строки
- **THEN** общее число линий равно 10

### Requirement: Уровень
Уровень SHALL быть равен целой части от деления общего числа линий на 10 (`lines // 10`) и SHALL пересчитываться после каждой фиксации, уже после начисления очков. Верхней границы у уровня нет.

#### Scenario: Переход на уровень 1
- **WHEN** при 8 линиях на уровне 0 фиксация удаляет 2 строки
- **THEN** линий 10, уровень 1

#### Scenario: Очки считаются по уровню до фиксации
- **WHEN** при 9 линиях, уровне 0 и 0 очках фиксация удаляет 4 строки
- **THEN** очки равны 1200 (множитель уровня 0), линий 13, уровень 1

#### Scenario: Высокий уровень
- **WHEN** общее число линий достигает 205
- **THEN** уровень равен 20
