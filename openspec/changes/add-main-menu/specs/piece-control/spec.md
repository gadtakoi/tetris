# Spec Delta

## MODIFIED Requirements

### Requirement: Начало партии
При начале новой партии игра SHALL создавать пустое поле, выбирать активную и следующую фигуры генератором, размещать активную фигуру в позиции появления, сбрасывать признак конца игры, обнулять очки, общее число линий и число линий, удалённых последней фиксацией, а уровень SHALL устанавливать равным стартовому уровню партии — от 0 до 19, по умолчанию 0 (см. «Экран настроек» в `settings`). Начать новую партию SHALL быть возможно в любой момент, в том числе после окончания предыдущей.

#### Scenario: Состояние новой партии
- **WHEN** начинается новая партия со стартовым уровнем 0
- **THEN** поле пустое, активная фигура находится в позиции появления в ориентации 0, следующая фигура объявлена, признак конца игры не установлен
- **AND** очки, линии, уровень и число линий последней фиксации равны 0

#### Scenario: Перезапуск после конца игры
- **WHEN** партия окончена и начинается новая партия со стартовым уровнем 0
- **THEN** поле пустое, очки, линии и уровень равны 0, и игра снова принимает команды управления

#### Scenario: Партия со стартового уровня
- **WHEN** начинается новая партия со стартовым уровнем 5
- **THEN** уровень равен 5, очки и линии равны 0
