# Spec Delta

## Purpose

Распространение игры для Windows: сборка одного исполняемого файла, который запускается без установленного Python, и способ автоматически проверить собранный файл.

## ADDED Requirements

### Requirement: Сборка exe
Команда `python build_exe.py`, выполненная в окружении с зависимостями из `requirements.txt` и `requirements-build.txt`, SHALL создавать ровно один исполняемый файл `dist\tetris.exe`. Сборка SHALL завершаться с кодом 0 при успехе и ненулевым кодом при ошибке. Повторная сборка SHALL перезаписывать прежний `dist\tetris.exe`.

#### Scenario: Успешная сборка
- **WHEN** в окружении с установленными зависимостями выполняется `python build_exe.py`
- **THEN** команда завершается с кодом 0, и в папке `dist` есть файл `tetris.exe`

### Requirement: Запуск без Python
`tetris.exe` SHALL запускаться двойным щелчком на Windows 10/11 x64, на которой не установлен Python, SHALL открывать окно игры без окна консоли и SHALL давать то же поведение, что `python -m tetris_ui`, включая шрифты, звук и сохранение рекордов, если они реализованы к моменту сборки.

#### Scenario: Двойной щелчок
- **WHEN** пользователь дважды щёлкает `tetris.exe`
- **THEN** открывается окно «Tetris» с новой партией, окно консоли не появляется

### Requirement: Автономность
`tetris.exe` SHALL NOT требовать никаких файлов рядом с собой и SHALL NOT создавать файлы рядом с собой. Данные игры (рекорды) SHALL храниться в папке данных пользователя, как при запуске из исходников.

#### Scenario: Копия в другую папку
- **WHEN** `tetris.exe` скопирован в пустую папку и запущен
- **THEN** игра запускается, и после её закрытия в этой папке по-прежнему только `tetris.exe`

### Requirement: Автоматическая проверка запуска
И `tetris.exe`, и `python -m tetris_ui` SHALL принимать необязательный параметр `--max-frames N` (N — целое ≥ 1): игра SHALL отрисовать N кадров и завершиться с кодом 0. Без параметра игра SHALL работать до закрытия окна. Некорректное значение (не целое или меньше 1) SHALL приводить к завершению с ненулевым кодом без открытия окна.

#### Scenario: Проверка exe без экрана
- **WHEN** `tetris.exe --max-frames 30` запускается с переменными окружения `SDL_VIDEODRIVER=dummy` и `SDL_AUDIODRIVER=dummy`
- **THEN** процесс завершается с кодом 0 не дольше чем за 30 секунд

#### Scenario: Некорректный параметр
- **WHEN** выполняется `python -m tetris_ui --max-frames 0`
- **THEN** процесс завершается с ненулевым кодом, окно не открывается
