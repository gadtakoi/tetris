# Spec Delta

## ADDED Requirements

### Requirement: Тень фигуры
Во время партии и на паузе клетки тени активной фигуры, находящиеся в видимых строках и не совпадающие с клетками самой активной фигуры, SHALL рисоваться цветом (r // 4, g // 4, b // 4), где (r, g, b) — цвет типа активной фигуры. Тень SHALL рисоваться под активной фигурой: где они совпадают, видна активная фигура. После конца игры тень SHALL NOT рисоваться.

#### Scenario: Тень фигуры T
- **WHEN** во время партии активная фигура T только появилась на пустом поле
- **THEN** центры клеток (4,20), (3,21), (4,21), (5,21) имеют цвет (40, 0, 60)

#### Scenario: Фигура на дне закрывает тень
- **WHEN** активная фигура T опущена до дна пустого поля
- **THEN** центры её клеток имеют цвет (160, 0, 240)

#### Scenario: Нет тени после конца игры
- **WHEN** партия окончена
- **THEN** ни одна клетка поля не нарисована цветом тени
