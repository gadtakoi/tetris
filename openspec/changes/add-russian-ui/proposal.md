# Proposal

## Why

Все надписи игры английские, а игрок и его аудитория русскоязычные. Игрок попросил русский интерфейс с возможностью переключения и английским по умолчанию. Пункт выбора языка уже появляется в настройках с `add-main-menu`, а это изменение даёт сам перевод.

## What Changes

- При выборе «Language: Русский» все надписи сразу становятся русскими: панель, пауза, конец игры, таблица рекордов, главное меню, экраны настроек, рекордов и списка клавиш.
- Язык сохраняется между запусками. По умолчанию английский.
- Не переводятся:
  - название «SEVA Tetris» и заголовок окна;
  - имена игроков, числа и проценты;
  - названия языков «English» и «Русский»;
  - обозначения клавиш, одинаковые в обоих языках (Z / Ctrl, C / Shift, P / Esc, F1, M, N, - / +, 9 / 0, Enter).
- Все надписи на обоих языках помещаются в свои области. Если русская надпись не влезает основным шрифтом (например, «ИГРА ОКОНЧЕНА» шире поля), она выводится шрифтом меньшего размера.
- Встроенный шрифт кириллицу поддерживает, это уже видно по именам в таблице рекордов.

## Вне рамок

- Другие языки и перевод названия игры.
- Перевод инструкции для игрока (`add-user-guide` пишет её на русском) и документации.
- Автоматический выбор языка по языку системы.

## Capabilities

### New Capabilities
- `localization`: языки интерфейса, таблица русских надписей, правило размещения надписей.

## Impact

- Новый модуль `tetris_ui/texts.py` без pygame: таблица переводов и функции подстановки.
- `tetris_ui/layout.py`: все надписи через перевод. `tetris_ui/render.py`: подбор размера шрифта по ширине области.
- Тесты `test_texts.py` (новый), `test_input.py`, `test_ui_smoke.py`; `docs/interface.md`, `docs/architecture.md`.
- Реализуется после `add-main-menu`: перевод включает надписи меню и настроек.
