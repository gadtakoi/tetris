# Design

## Context

`Randomizer(rng).next()` сейчас вызывает `rng.choice(list(PieceType))`. `Game.new_game()` берёт из генератора активную и следующую фигуры. Тесты сценариев подставляют `tests/helpers.ScriptedRng` — наследника `random.Random`, у которого `choice()` возвращает заранее заданную последовательность (с повторами, например «одни O»). Он используется в 33 местах тестов. Мотивация описана в proposal.md, требование — в дельте `tetrominoes`.

## Goals / Non-Goals

**Goals:**
- Настоящий 7-bag с воспроизводимостью по seed.
- Существующие тесты со сценарными последовательностями продолжают работать без правок в местах вызова.

**Non-Goals:**
- Сохранение прежних последовательностей для тех же seed: они изменятся, и ни один тест от конкретной последовательности по seed не зависит.

## Decisions

### Мешок через `rng.shuffle`
```python
class Randomizer:
    def next(self) -> PieceType:
        if not self._bag:
            self._bag = list(PieceType)
            self._rng.shuffle(self._bag)
        return self._bag.pop(0)

    def reset(self) -> None:
        self._bag = []
```
`Game.new_game()` сначала вызывает `reset()`, поэтому каждая партия начинается с нового мешка.

Альтернатива — `rng.choice(оставшиеся)` с удалением выбранного. Она тоже даёт мешок, но ломает сценарные тесты: `ScriptedRng` возвращает, например, O повторно, а её в остатке мешка уже нет. С `shuffle` двойник сам решает, что лежит в мешке.

### Тестовый двойник
`ScriptedRng.shuffle(seq)` заполняет переданный список следующими `len(seq)` фигурами сценария (`seq[:] = [...]`). Так `Randomizer.next()` выдаёт ровно сценарную последовательность, включая повторы, которых в настоящем мешке не бывает. `choice()` больше не нужен генератору, но остаётся в двойнике на случай прямого использования в тестах.

## Risks / Trade-offs

- [Сценарные тесты проверяют логику на последовательностях, невозможных при настоящем мешке (пять O подряд)] → это осознанно: сценарии проверяют правила поля и фиксации, а свойства мешка проверяют отдельные тесты генератора на настоящем `random.Random`.

## Migration Plan

Не требуется: состояние игры не сохраняется между запусками.
