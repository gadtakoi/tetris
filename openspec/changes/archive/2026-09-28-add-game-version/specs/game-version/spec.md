# Spec Delta

## Purpose

Номер версии игры и то, где его видит игрок: в главном меню и в свойствах файла `SEVA Tetris.exe`, чтобы по любой копии игры можно было понять, какая это сборка.

## ADDED Requirements

### Requirement: Номер версии
Игра SHALL иметь номер версии вида MAJOR.MINOR.PATCH — три целых неотрицательных числа через точку без ведущих нулей. Текущая версия — 1.0.0. Главное меню и свойства `SEVA Tetris.exe` SHALL показывать один и тот же номер, и при запуске из исходников (`python -m tetris_ui`) SHALL показываться тот же номер, что в собранном exe.

#### Scenario: Текущая версия
- **WHEN** игра запущена командой `python -m tetris_ui`
- **THEN** в главном меню показана надпись «v1.0.0»

#### Scenario: Один номер везде
- **WHEN** собран `SEVA Tetris.exe`
- **THEN** версия продукта в его свойствах совпадает с номером в надписи главного меню без буквы «v»

### Requirement: Версия в главном меню
В главном меню SHALL показываться надпись «v<номер версии>» (сейчас «v1.0.0») цветом (130, 130, 140):
- правый край надписи — не правее x = 510;
- нижний край — не ниже y = 630;
- надпись SHALL NOT перекрывать пункты меню и подсказку «Up / Down - choose, Enter - select».

Надпись SHALL быть одинаковой на обоих языках интерфейса. На других экранах надпись SHALL NOT показываться: на экранах рекордов, настроек и списка клавиш, в инструкции, во время партии, на паузе и после конца игры.

#### Scenario: Версия в меню
- **WHEN** открыто главное меню
- **THEN** показана надпись «v1.0.0» цветом (130, 130, 140), целиком внутри окна, правее x = 260 и ниже подсказки

#### Scenario: Версия на русском
- **WHEN** выбран русский язык, и открыто главное меню
- **THEN** показана та же надпись «v1.0.0»

#### Scenario: Только в главном меню
- **WHEN** открыт экран настроек или идёт партия
- **THEN** надписи «v1.0.0» на экране нет

### Requirement: Версия в свойствах exe
`SEVA Tetris.exe` SHALL содержать ресурс версии Windows с такими значениями:

| Поле | Значение |
|---|---|
| Версия файла (FileVersion) | <номер версии>.0, сейчас 1.0.0.0 |
| Версия продукта (ProductVersion) | <номер версии>, сейчас 1.0.0 |
| Название продукта (ProductName) | SEVA Tetris |
| Описание файла (FileDescription) | SEVA Tetris |
| Исходное имя файла (OriginalFilename) | SEVA Tetris.exe |

Проводник Windows SHALL показывать эти значения на вкладке «Подробно» свойств файла.

Ресурс версии SHALL храниться в файле `version_info.txt` в корне проекта. Этот файл SHALL храниться в git (его не исключает `.gitignore`) и SHALL соответствовать текущему номеру версии; сборка берёт ресурс версии из него.

#### Scenario: Свойства собранного exe
- **WHEN** командой `python build_exe.py` собран `SEVA Tetris.exe`
- **THEN** версия файла 1.0.0.0, версия продукта 1.0.0, название продукта «SEVA Tetris», исходное имя файла «SEVA Tetris.exe»

#### Scenario: Файл версии в репозитории
- **WHEN** номер версии — 1.0.0
- **THEN** в корне проекта есть `version_info.txt` с версией файла 1.0.0.0 и версией продукта 1.0.0, и git его не игнорирует
