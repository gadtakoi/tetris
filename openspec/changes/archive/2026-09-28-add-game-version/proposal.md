# Proposal

## Why

У игры нет номера версии. Когда `SEVA Tetris.exe` передают другим людям, нельзя понять, какая сборка у кого стоит и есть ли в ней нужные исправления. Игрок попросил добавить версию игры.

## What Changes

- **Номер версии:** 1.0.0 в формате MAJOR.MINOR.PATCH. Номер задаётся в одном месте кода и меняется вручную перед выпуском новой сборки.
- **Версия в главном меню:** мелкая надпись «v1.0.0» в правом нижнем углу. Она одинакова на обоих языках и есть только в главном меню.
- **Версия в свойствах `SEVA Tetris.exe`:** в Windows «Свойства → Подробно» показывают:
  - версию файла 1.0.0.0;
  - версию продукта 1.0.0;
  - название и описание «SEVA Tetris»;
  - исходное имя файла.
- **Документация:**
  - `docs/build.md`: как поднять версию и когда менять каждую из трёх цифр;
  - `docs/user-guide.md`: где посмотреть версию.

## Вне рамок

- Автоматическое увеличение номера: по дате, по коммитам git или по тегам.
- Параметр `--version` в командной строке.
- Версия в заголовке окна и в инструкции (F2).
- Цифровая подпись exe, авторские права и название компании в свойствах файла.
- Проверка обновлений и журнал изменений в игре.

## Capabilities

### New Capabilities
- `game-version`: номер версии игры, его показ в главном меню и в свойствах `SEVA Tetris.exe`.

## Impact

- `tetris_ui/__init__.py`: константа `__version__` — единственное место, где задан номер.
- `tetris_ui/layout.py` и `tetris_ui/render.py`: надпись версии в главном меню.
- `build_exe.py` и новый `version_info.txt` в корне проекта (хранится в git): ресурс версии для PyInstaller (`--version-file`). Сборка обновляет файл из `tetris_ui.__version__`.
- Тесты:
  - `tests/test_version.py` (новый): формат номера и текст ресурса версии;
  - `test_input.py` и `test_ui_smoke.py`: надпись в меню;
  - `test_build.py`: свойства собранного exe.
- Документация: `docs/build.md`, `docs/interface.md`, `docs/user-guide.md`.
- Реализуется после `add-in-game-guide`: оба изменения правят главное меню и `docs/user-guide.md`.
