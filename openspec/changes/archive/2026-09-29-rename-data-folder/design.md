# Design

## Context

Мотивация — в proposal.md, требование — в дельте `high-scores` («Хранение таблицы»).

- `storage.data_dir()` возвращает `TETRIS_DATA_DIR`, если переменная задана и не пуста. Иначе — `%APPDATA%\<APP_DIR_NAME>`, если есть `APPDATA`, а без неё — `~/.local/share/<APP_DIR_NAME>`. Сейчас `APP_DIR_NAME = "tetris"`.
- `high_scores_path()`, `settings_path()` и `sound_check_path()` строятся от `data_dir()`, поэтому все три файла меняют папку вместе.
- Все тесты, которые запускают программу, задают `TETRIS_DATA_DIR` во временной папке: `tests/test_cli.py`, `tests/test_ui_smoke.py`, `tests/test_audio.py`, `tests/test_build.py`. Тесты `data_dir()` в `tests/test_storage.py` подменяют `APPDATA` через `monkeypatch`.
- Активное изменение `add-signed-highscores` кладёт в эту же папку файл `install-id`. Требование «Хранение таблицы» оно меняет только после архивирования этого изменения.

## Goals / Non-Goals

**Goals:**
- Имя папки данных задано в одном месте — `storage.APP_DIR_NAME`.

**Non-Goals:**
- Любая работа с прежней папкой `%APPDATA%\tetris`: игра даже не проверяет, есть ли она.

## Decisions

### Имя папки — `storage.APP_DIR_NAME = "tetris_shmetris"`
Меняется одна константа: на ней уже построены `data_dir()` и пути ко всем трём файлам. Docstring `data_dir()` называет новую папку.

Константа остаётся отдельной и не берётся из `build_exe.EXE_NAME` или `tetris_ui.GAME_TITLE`:
- `build_exe.py` — скрипт сборки вне пакета;
- в `GAME_TITLE` есть пробел и заглавные буквы;
- главное — папка данных должна меняться только по отдельному решению. Если бы её имя шло от имени exe, следующее переименование игры незаметно оставило бы игрока без рекордов и настроек.

Отвергнуто: **общее «имя приложения» в `tetris_ui/__init__.py` и для exe, и для папки** — по последней причине.

### Прежней папки в коде нет
Код не хранит прежнее имя папки и не обращается к ней. Поэтому из неё ничего не читается, не переносится и не удаляется. Сценарий «Прежняя папка не читается» проверяет тест с `APPDATA` во временной папке: файлы в `<APPDATA>\tetris` не влияют на загрузку и не меняются после сохранения.

Отвергнуто: **перенос файлов из прежней папки при запуске** — игрок от него отказался.

### Документация
- `docs/architecture.md`, «Данные на диске»: таблица папок.
- `docs/interface.md`, «Хранение данных»: папка данных.
- `docs/build.md`: папка данных exe.
- `docs/user-guide.md`, «Где хранятся данные»: папка и команда для Win + R.
- `openspec/config.yaml`: папка данных в разделе «Архитектура».
- Инструкция в игре (`tetris_ui/guide.py`) папку данных не упоминает и не меняется.

## Risks / Trade-offs

- [После обновления игрок не видит прежних рекордов и настроек] → Это решение игрока. Прежние файлы остаются на диске в `%APPDATA%\tetris`.
- [Прежняя сборка 1.0.0 и новая работают с разными папками] → Их данные не пересекаются, и одна сборка не портит файлы другой.
- [Тест без `TETRIS_DATA_DIR` писал бы в настоящую папку данных] → Все тесты, которые запускают программу, задают переменную, а тесты `data_dir()` подменяют `APPDATA`.

## Migration Plan

Переноса нет. Первый запуск новой версии начинает с пустой таблицей и настройками по умолчанию, а папка `%APPDATA%\tetris_shmetris` появляется при первом сохранении. Откат: вернуть `APP_DIR_NAME = "tetris"`. Тогда игра снова увидит прежние файлы, а файлы из `%APPDATA%\tetris_shmetris` останутся на диске.
