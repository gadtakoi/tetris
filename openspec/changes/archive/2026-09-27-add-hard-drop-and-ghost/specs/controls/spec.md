# Spec Delta

## MODIFIED Requirements

### Requirement: Клавиши управления
Во время партии (не на паузе и не после конца игры) нажатие клавиши SHALL вызывать ровно одну команду логики:

| Клавиша | Команда |
|---|---|
| ← | сдвиг влево |
| → | сдвиг вправо |
| ↓ | шаг вниз (мягкое падение) |
| Пробел | жёсткое падение |
| ↑, X | вращение по часовой |
| Z, левый Ctrl | вращение против часовой |

Остальные клавиши SHALL NOT вызывать команды фигуре.

#### Scenario: Сдвиг влево
- **WHEN** во время партии нажата клавиша ←
- **THEN** выполнена ровно одна команда «сдвиг влево»

#### Scenario: Вращение двумя клавишами
- **WHEN** во время партии нажаты по очереди ↑ и X
- **THEN** выполнены ровно две команды «вращение по часовой»

#### Scenario: Жёсткое падение по пробелу
- **WHEN** во время партии нажат Пробел
- **THEN** выполнена ровно одна команда «жёсткое падение»

#### Scenario: Посторонняя клавиша
- **WHEN** во время партии нажата клавиша A
- **THEN** ни одна команда фигуре не выполнена

## ADDED Requirements

### Requirement: Жёсткое падение без автоповтора
Удержание Пробела SHALL NOT повторять жёсткое падение: одно нажатие даёт одну команду, даже если за время удержания появилась новая фигура. На паузе и после конца игры Пробел SHALL NOT вызывать команд.

#### Scenario: Удержание пробела
- **WHEN** во время партии Пробел удерживается 1000 мс
- **THEN** выполнена ровно одна команда «жёсткое падение»

#### Scenario: Пробел на паузе
- **WHEN** игра на паузе и нажат Пробел
- **THEN** ни одна команда фигуре не выполнена
