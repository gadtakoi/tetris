# Proposal

## Why

Проект пустой: пока нет ни одной строчки игровой логики. Правила тетриса (поле, фигуры, движение, вращение, коллизии, фиксация) — основа, на которую опираются все остальные части: гравитация, очистка линий, очки, отрисовка. Поэтому их нужно описать и реализовать первыми, отдельно от pygame, чтобы поведение было детерминированным и покрытым тестами до появления интерфейса.

## What Changes

- Игровое поле 10 × 20 видимых клеток плюс 2 скрытые буферные строки сверху для появления фигур; хранение занятых клеток и их типа фигуры.
- Семь тетромино (I, O, T, S, Z, J, L) с фиксированными таблицами состояний вращения.
- Генератор фигур: равновероятный случайный выбор с внедряемым источником случайности (seed) и доступом к следующей фигуре для будущего превью.
- Управление активной фигурой: сдвиг влево/вправо, шаг вниз (мягкое падение), вращение по и против часовой стрелки. Любой ход, приводящий к коллизии со стенами, дном или занятыми клетками, отклоняется без изменения состояния.
- Фиксация фигуры: если шаг вниз невозможен, фигура сразу записывается в поле и появляется следующая.
- Определение конца игры: новая фигура не может появиться, потому что её позиция появления занята (block out). Логика выставляет флаг конца игры и больше не принимает ходов.
- Публичный API логики — чистый Python без зависимостей от pygame, с тестами pytest.

## Вне рамок

- Гравитация по времени, уровни и рост скорости — отдельное изменение (логика здесь предоставляет только команду «шаг вниз»).
- Очистка заполненных линий и подсчёт очков — отдельное изменение.
- Отрисовка, окно pygame, обработка клавиатуры, пауза, экраны меню и game over.
- Hard drop, ghost-фигура, hold, 7-bag, SRS wall kicks, задержка фиксации (lock delay).
- Таблица рекордов, звук и музыка.

## Capabilities

### New Capabilities
- `playfield`: размеры поля, скрытая буферная зона, хранение занятых клеток, проверка границ и занятости.
- `tetrominoes`: формы семи фигур, их состояния вращения, позиция появления, генератор фигур и следующая фигура.
- `piece-control`: команды управления активной фигурой (сдвиг, шаг вниз, вращение), отклонение ходов при коллизии, фиксация, появление следующей фигуры и определение конца игры.

## Impact

- Новый пакет `tetris/` с модулями логики (без импорта pygame).
- Новый каталог `tests/` с тестами pytest.
- Новый `requirements.txt` (на этом этапе нужен только `pytest`; `pygame-ce` добавится вместе с интерфейсом).
- Внешних API и существующего кода, который мог бы сломаться, нет.
