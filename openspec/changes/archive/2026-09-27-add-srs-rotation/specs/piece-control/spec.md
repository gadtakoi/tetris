# Spec Delta

## MODIFIED Requirements

### Requirement: Вращение
Команды «вращение по часовой» и «вращение против часовой» SHALL переводить активную фигуру в соседнюю ориентацию по системе SRS (Super Rotation System). Ориентации: 0 — исходная, 1 — после поворота по часовой из 0, 2 — после двух поворотов, 3 — после поворота против часовой из 0. Сначала SHALL пробоваться поворот на месте: рамка фигуры не смещается. Если это положение недопустимо, SHALL по очереди пробоваться четыре смещения из таблицы для данного перехода, и фигура SHALL занимать первое допустимое положение. Если ни одно из пяти положений недопустимо, поворот SHALL отклоняться, и фигура остаётся на месте в прежней ориентации. Смещение (dx, dy) задаётся в клетках: dx — вправо, dy — вверх (столбец увеличивается на dx, строка уменьшается на dy).

Смещения для J, L, S, T и Z:

| Переход | Смещения по порядку |
|---|---|
| 0 → 1 | (−1, 0), (−1, +1), (0, −2), (−1, −2) |
| 1 → 0 | (+1, 0), (+1, −1), (0, +2), (+1, +2) |
| 1 → 2 | (+1, 0), (+1, −1), (0, +2), (+1, +2) |
| 2 → 1 | (−1, 0), (−1, +1), (0, −2), (−1, −2) |
| 2 → 3 | (+1, 0), (+1, +1), (0, −2), (+1, −2) |
| 3 → 2 | (−1, 0), (−1, −1), (0, +2), (−1, +2) |
| 3 → 0 | (−1, 0), (−1, −1), (0, +2), (−1, +2) |
| 0 → 3 | (+1, 0), (+1, +1), (0, −2), (+1, −2) |

Смещения для I:

| Переход | Смещения по порядку |
|---|---|
| 0 → 1 | (−2, 0), (+1, 0), (−2, −1), (+1, +2) |
| 1 → 0 | (+2, 0), (−1, 0), (+2, +1), (−1, −2) |
| 1 → 2 | (−1, 0), (+2, 0), (−1, +2), (+2, −1) |
| 2 → 1 | (+1, 0), (−2, 0), (+1, −2), (−2, +1) |
| 2 → 3 | (+2, 0), (−1, 0), (+2, +1), (−1, −2) |
| 3 → 2 | (−2, 0), (+1, 0), (−2, −1), (+1, +2) |
| 3 → 0 | (+1, 0), (−2, 0), (+1, −2), (−2, +1) |
| 0 → 3 | (−1, 0), (+2, 0), (−1, +2), (+2, −1) |

Фигура O поворачивается без смещений: её клетки во всех ориентациях одинаковы.

#### Scenario: Вращение на свободном поле
- **WHEN** активная фигура T только появилась на пустом поле и выполняется «вращение по часовой»
- **THEN** фигура находится в ориентации 1 и занимает клетки (4,2), (4,3), (5,3), (4,4)

#### Scenario: Вращение у стены отклоняется
- **WHEN** вертикальная фигура I в ориентации 1 стоит в колодце шириной в один столбец: её клетки (0,18), (0,19), (0,20), (0,21), а столбцы 1–9 в строках 10–21 заняты; выполняется «вращение по часовой»
- **THEN** ни одно из пяти положений недопустимо, поворот отклоняется, и фигура остаётся в ориентации 1 на том же месте

#### Scenario: Вращение в скрытую зону разрешено
- **WHEN** активная фигура I только появилась и выполняется «вращение по часовой»
- **THEN** поворот выполняется, и фигура занимает клетки (5,1), (5,2), (5,3), (5,4), включая клетку скрытой строки 1

#### Scenario: Отскок I от стены
- **WHEN** на пустом поле вертикальная фигура I в ориентации 1 прижата к левой стене: её клетки (0,1), (0,2), (0,3), (0,4); выполняется «вращение по часовой»
- **THEN** поворот на месте и первое смещение (−1, 0) недопустимы, второе смещение (+2, 0) подходит, и фигура в ориентации 2 занимает клетки (0,3), (1,3), (2,3), (3,3)

#### Scenario: Отскок T от стены
- **WHEN** на пустом поле фигура T в ориентации 1 прижата к левой стене: её клетки (0,2), (0,3), (1,3), (0,4); выполняется «вращение против часовой»
- **THEN** фигура сдвигается на (+1, 0) и в ориентации 0 занимает клетки (1,2), (0,3), (1,3), (2,3)

#### Scenario: Отскок от пола
- **WHEN** фигура T в ориентации 0 лежит на дне пустого поля: её клетки (4,20), (3,21), (4,21), (5,21); выполняется «вращение по часовой»
- **THEN** поворот на месте и смещение (−1, 0) выходят за дно, смещение (−1, +1) подходит, и фигура в ориентации 1 занимает клетки (3,19), (3,20), (4,20), (3,21)
