# Сборка SEVA Tetris.exe

Игру можно собрать в один файл `SEVA Tetris.exe`, который запускается двойным щелчком на Windows 10/11 x64 без установленного Python.

## Как собрать

```bat
.venv\Scripts\python -m pip install -r requirements.txt -r requirements-build.txt
.venv\Scripts\python build_exe.py
```

`requirements-build.txt` содержит только PyInstaller: он нужен для сборки, но не для игры и тестов, поэтому отделён от `requirements.txt`.

Сборка занимает около 20–30 секунд. Результат — `dist\SEVA Tetris.exe` (около 15 МБ). Промежуточные файлы попадают в `build\` и `SEVA Tetris.spec`; как и `dist\`, они игнорируются git. Файл `dist\tetris.exe` от сборок до переименования игры удаляется после успешной сборки.

## Как устроена сборка

- `build_exe.py` запускает PyInstaller с параметрами `--onefile --windowed --name "SEVA Tetris" --clean --noconfirm` и `--version-file` (см. «Версия»): один файл, без окна консоли, каждый раз с чистого листа. Скрипт возвращает 0 только если `SEVA Tetris.exe` действительно появился.
- Точка входа — `launcher.py`, который вызывает `tetris_ui.cli.run()`, как и `python -m tetris_ui`. Имя `tetris.py` для него не подходит: оно совпало бы с пакетом `tetris`.
- pygame-ce поставляет собственный хук PyInstaller, поэтому библиотеки SDL и встроенный шрифт попадают в exe автоматически. Звуки синтезируются в коде, других ресурсов нет.
- В exe без консоли `sys.stderr` равен `None`, поэтому предупреждения выводятся через `cli.warn()`, который в этом случае молчит.
- Данные (рекорды, настройки) хранятся в `%APPDATA%\tetris`, а не рядом с exe: файл можно переносить куда угодно, а рядом с ним ничего не создаётся.

## Версия

Номер версии задан в одном месте — `__version__` в `tetris_ui/__init__.py`, сейчас 1.0.0, в формате MAJOR.MINOR.PATCH. Его видно в двух местах:
- **в игре** — надпись «v1.0.0» в правом нижнем углу главного меню;
- **в свойствах exe** — ресурс версии Windows из файла `version_info.txt` в корне проекта.

Как устроен `version_info.txt`:
- Файл хранится в git, поэтому данные ресурса версии видны в репозитории и в его истории.
- Перед каждой сборкой `build_exe.py` заново составляет его текст из `__version__` (`version_info_text()`) и перезаписывает файл, только если текст изменился (`write_version_file()`).
- PyInstaller получает файл параметром `--version-file`.
- Обычный тест проверяет, что `version_info.txt` соответствует `__version__` и не исключён `.gitignore`.

Значения ресурса версии:
- версия файла — номер с четвёртой частью 0 (1.0.0.0);
- версия продукта — сам номер (1.0.0);
- название продукта и описание файла — «SEVA Tetris»;
- исходное имя файла — `SEVA Tetris.exe`.

**Когда какую цифру менять:**
- **PATCH** (1.0.0 → 1.0.1) — только исправления ошибок;
- **MINOR** (1.0.0 → 1.1.0) — новые возможности, с которыми прежние рекорды и настройки читаются как раньше;
- **MAJOR** (1.0.0 → 2.0.0) — несовместимые изменения, например новый формат `highscores.json` или `settings.json`, который старые версии не прочитают.

Номер поднимают вручную перед сборкой версии, которую отдают игрокам; промежуточные сборки для проверки его не меняют. После нового номера сборка обновит `version_info.txt` (и напишет об этом) — закоммитьте его вместе с `tetris_ui/__init__.py`, иначе тест сообщит, что файл устарел. Проверить результат: правый щелчок по `dist\SEVA Tetris.exe` → «Свойства» → вкладка «Подробно».

## Как проверить

Автоматически — сборочный тест. Он долгий, поэтому обычный `pytest` его пропускает:

```bat
set TETRIS_BUILD_TEST=1
.venv\Scripts\python -m pytest tests/test_build.py
```

Тест собирает exe, проверяет удаление старого `tetris.exe`, копирует `SEVA Tetris.exe` в пустую временную папку, запускает его без экрана (`SDL_VIDEODRIVER=dummy`, `SDL_AUDIODRIVER=dummy`, `--max-frames 30`) и проверяет код 0 и то, что рядом с exe ничего не появилось. Второй тест читает свойства собранного exe через PowerShell (`(Get-Item …).VersionInfo`) и сверяет версию файла и продукта, название и исходное имя с `tetris_ui.__version__` и надписью в главном меню.

Вручную — дважды щёлкнуть `dist\SEVA Tetris.exe`: открывается окно «SEVA Tetris» с главным меню, консоли нет.

## Известные ограничения

- **Первый запуск медленнее.** Однофайловый exe каждый раз распаковывается во временную папку, а музыка синтезируется при запуске, поэтому окно появляется через несколько секунд.
- **Антивирусы.** Однофайловые сборки PyInstaller без цифровой подписи иногда вызывают ложные срабатывания антивирусов.
- **Только Windows x64.** Сборки для других систем не делаются.

Точные требования: [distribution](../openspec/specs/distribution/spec.md), [game-version](../openspec/specs/game-version/spec.md).
